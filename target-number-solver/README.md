# 数式パズルソルバー

**制作時期：** 専門学校2年生（個人制作）/ ポートフォリオ公開時に一部改良

## 概要

指定した数字を四則演算で組み合わせて、目標の値を導く数式を自動で探索するWebツールです。  
パズルゲームの問題を解くために制作しました。

---

## 起動方法

1. `target-number-solver.html` をブラウザで開く

---

## 使い方

1. 数字の入力欄に使う数字を1つずつ入力する（＋ボタンで枠を追加、×ボタンで削除）
2. 「目標の合計」欄に作りたい目標値を入力する
3. 「解答する」ボタンを押すと、目標値になる数式が表示される
4. 解が存在しない場合は「不可能です」と表示される
5. 「リセット」ボタンで入力をすべてクリアできる

## 改良について

当初はカンマ区切りのテキスト入力（例：`1,6,8,8`）で数字を入力する形式でした。利用者がカンマを意識して入力する必要があり、使いにくいと感じたため、数字ごとに個別の入力ボックスを用意する形に改良しました。＋ボタンで枠を追加、×ボタンで不要な枠を削除できるようにしています。

---

## 機能

- 数字と目標値を入力するだけで、成立する数式を自動で探索・表示
- 解が存在しない場合のフィードバック表示
- リセット機能

---

## 使用技術

- HTML
- JavaScript (Vanilla)

---

## 工夫した点

- 数字の全順列と演算子（+・-・×・÷）の全組み合わせを再帰関数で探索するアルゴリズムを自力で実装した
- 除算を含む計算で発生する浮動小数点誤差を考慮し、`Math.abs(val - target) < 1e-9` による比較で誤判定を防止した
