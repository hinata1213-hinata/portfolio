# Photo Reveal

**制作時期：** 専門学校4年生（個人制作）

## 概要

選んだ写真が粒子から少しずつ形になっていき、「早く当てるほど高得点」という遊び方ができるブラウザアプリです。  
HTML5 Canvas と JavaScript のみで制作し、外部ライブラリは使用していません。

---

## 起動方法

1. `index.html` をブラウザで開く

---

## 使い方

1. 「写真を選択」から手持ちの画像を選ぶ（選ばない場合はサンプル画像で動作する）
2. 写真がぼやけた粒子の状態から徐々に復元されていくので、何が写っているかを当てる
3. 早く分かるほど高得点（5 Pts → 1 Pts と時間経過で減点）
4. 「再スタート」でやり直し、「完成時間」ボタンで 5 / 8 / 12 / 20 秒を切り替え

---

## 機能

- 端末内の画像を読み込んで粒子アニメーションに変換（画像はアップロードせずブラウザ内で完結）
- 経過時間に応じたポイント表示とプログレスバー、目盛りによる減点タイミングの可視化
- 完成時間の切り替え（5 / 8 / 12 / 20 秒）
- スマホでの全画面表示に対応（セーフエリア考慮・ホーム画面追加時のアプリ表示設定）

## 使用技術

- CSS

## 工夫した点

- 粒子の到着順を乱数ではなく **R2 低差異列**（`gx * 0.7548776662 + gy * 0.5698402909`）で決定し、途中のどの瞬間でも画面全体に均等に粒子が並ぶようにした。序盤から「粗い写真」として読み取れるため、当てる遊びとして成立させられた
- 早く確定する粒子ほど遠くから飛来し、後の粒子は近くから収まるよう距離を `pow(1 - ord, 2.2)` で重み付けし、中盤に取り残された粒子が散らばって見えないようにした
- 背面に縮小画像を重ね、経過時間に応じて解像度（`4 + t^2.2 * 420` px）と不透明度を上げることで「ピントが合っていく」表現を実装
- `getImageData` の走査ステップを画像サイズから決め、粒子数の上限（13,000）を超える場合は間引くことでスマートフォンでも描画負荷を抑えた
- `devicePixelRatio` を上限 2 でクランプしてリサイズに追従させ、高精細画面でも解像度と処理負荷を両立させた
