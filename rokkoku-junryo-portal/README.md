# 六刻巡旅 公式ポータル

**制作時期：** 専門学校3年生・プロジェクト演習3（チーム制作）

## 概要

チームで制作した伝奇ホラーサウンドノベルゲーム「六刻巡旅」の公式ポータルサイトです。  
ゲームの紹介・配布ページと、プレイヤー同士が交流できるコミュニティ掲示板を一から設計・実装しました。

---

## 構成

```
rokkoku-junryo-portal/
├── game.html          # ゲーム紹介・ダウンロードページ
├── game.css           # メインページのスタイル
├── game.js            # パーティクル・スライドショーなどのインタラクション
├── Images/            # 背景画像
├── legal/             # プライバシーポリシー・利用規約
├── community/         # コミュニティ掲示板（PHP）
├── bonus/             # ボーナスコンテンツ（パスワード認証）
├── C34_admin_dashboard/ # 管理者ダッシュボード
└── RokkokuJunryo Unity/ # ゲーム本体（Unity プロジェクト）
```

---

## 機能

### ゲーム紹介ページ
- ゲームの紹介・ダウンロード配布
- パーティクルエフェクトとクロスフェードスライドショーによる演出
- あらすじ動画の埋め込み
- レスポンシブ対応（768px / 1200px ブレークポイント）

### コミュニティ掲示板
- ユーザー登録・ログイン・アカウント管理（編集・削除）
- 攻略・考察・Q&A の3部屋に分かれた掲示板への投稿・返信
- いいね機能と通知システム（返信・いいねの未読バッジ表示）
- キーワード検索
- NGワードフィルター

### その他
- ゲームクリア者向けパスワード認証ボーナスコンテンツ
- 管理者ダッシュボード（ユーザー一覧・アカウント管理）
- プライバシーポリシー・利用規約ページ

---

## 使用技術

- **ゲーム本体：** Unity (C#)
- **フロントエンド：** HTML5 / CSS3 / JavaScript (Vanilla)
- **バックエンド：** PHP
- **データベース：** SQLite
- **テンプレートエンジン：** BladeOne (Composer)

---

## セキュリティ対策

- bcrypt によるパスワードハッシュ化
- プリペアドステートメントによる SQL インジェクション対策
- `htmlspecialchars` による XSS 対策
- NGワードフィルターによる不適切投稿の自動ブロック

---

## 工夫した点

- MVC 構造を採用し、コントローラー・モデル・ビューに責務を分離して保守性を向上させた
- 通知システムを実装し、返信やいいねをリアルタイムに近い形でユーザーへフィードバックできるようにした
- ゲームのダークホラーな世界観に合わせたUI演出（青い雨パーティクルエフェクト・クロスフェードスライドショー）を JavaScript で実装した
- ゲームクリア者だけが解ける合言葉ヒント（各エンディングの特定文字を組み合わせる）を設けてボーナスコンテンツへのアクセスを制限した
