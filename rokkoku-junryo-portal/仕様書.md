# 六刻巡旅 - 最終仕様書

## プロジェクト概要

**六刻巡旅（ろっこくじゅんりょ）** は、伝奇ホラーサウンドノベルゲームとそのコミュニティWebサイトです。

---

## Web（メインページ）

### game.html
ゲームのランディングページ（トップページ）。
- タイトルセクション（背景スライドショー切り替え）
- あらすじ動画
- ゲームダウンロードボタン
- 3つのゲーム特徴紹介（伝奇ホラー・選択・マルチエンディング）
- コミュニティへのリンク
- おまけコンテンツへのリンク

### game.css
メインページのスタイルシート。
- ダークテーマ（黒・青を基調）
- パーティクルエフェクト用のスタイル
- 各セクションのレイアウト・アニメーション
- レスポンシブ対応（768px / 1200px ブレークポイント）

### game.js
メインページのインタラクティブ機能。
- 青い雨パーティクルエフェクト
- タイトル背景のクロスフェードスライドショー
- スクロールアニメーション
- ホバーサウンド効果

## コミュニティ

### community/rooms/index.php
コミュニティのメインハブページ。
- 3つの部屋へのリンク（攻略・考察・Q&A）
- 通知機能（返信・いいね通知）
- ログイン状態の表示
- ネタバレ警告バブル表示

**特筆点:** 通知はuser_idベースで管理、未読数をバッジ表示

### community/rooms/room_guide.php
ゲーム攻略情報部屋（room_id: 2）。
- ネタバレなしの攻略情報共有
- 3列グリッドでコメント表示
- 投稿・返信機能
- いいね機能

### community/rooms/room_discussion.php
考察・感想部屋（room_id: 3）。
- ネタバレありの考察・感想共有
- 3列グリッドでコメント表示
- 投稿・返信機能
- いいね機能

### community/rooms/room_qa.php
運営Q&A部屋（room_id: 4）。
- 運営チームへの質問
- 公式回答
- 3列グリッドでコメント表示

### community/rooms/post_detail.php
投稿詳細ページ。
- 親投稿を強調表示（📝 投稿ラベル）
- 返信を3列グリッドで表示
- 返信フォーム
- いいね機能
- 「(自分)」ラベルで自分の投稿を識別

**特筆点:** 親投稿と返信を視覚的に区別、user_idで自分の投稿を判定

### community/rooms/get_comments.php
コメント取得API（AJAX用）。
- room_idに基づいてコメントを取得
- いいね数・返信数を含む
- `is_own`フラグで自分の投稿を識別

### community/rooms/reply_to.php
返信投稿ページ。
- 親投稿への返信フォーム
- NGワードフィルタリング
- 通知作成（返信先ユーザーへ）

### community/rooms/like_action.php
いいね処理API（AJAX用）。
- いいねのトグル処理
- 通知作成（投稿者へ）

### community/rooms/my_likes.php
自分がいいねした投稿一覧ページ。
- いいねした投稿のリスト表示
- 投稿詳細へのリンク

### community/rooms/search.php
コミュニティ検索ページ。
- キーワード検索
- 検索結果表示

### community/rooms/notifications.php
通知システム機能。
- 通知の取得・作成・既読処理
- 返信通知・いいね通知

### community/rooms/ng_word_filter.php
NGワードフィルター。
- 不適切な言葉の検出
- 投稿のブロック処理

## データベース

### community/data/rokkoku_users.db
ユーザー情報データベース（SQLite）。

**テーブル構造:**
```
users: id, username, password, created_at
```

### community/data/rokkoku_community.db
コミュニティデータベース（SQLite）。

**テーブル構造:**
```
room_comments: id, room_id, parent_id, user_id, name, content, created_at
comment_likes: id, comment_id, user_id, username, created_at
notifications: id, user_id, type, comment_id, from_user, is_read, created_at
```
