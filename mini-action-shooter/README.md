# ミニアクションシューター

**制作時期：** 専門学校2年生（個人制作）

## 概要

HTML5 Canvas と JavaScript のみを使って制作した、ブラウザ上で動作する2Dアクションシューティングゲームです。  
外部ライブラリを一切使わず、ゲームの仕組みをフルスクラッチで実装することを目標に制作しました。

---

## ゲームフロー

プレイヤーはジャンプしながら、空中に浮かぶ**青い水の球体**を足場にして戦います。  
敵は絶えず球体を撃ち込んでくるため、それを回避しながら隙をみてこちらも射撃で反撃します。

- 青い水の球体に一度乗ると、地上に降りることができなくなる
- 空中での位置取りと回避が攻略のカギ

---

## 起動方法

1. `index.html` をブラウザで開く
2. キーボードで操作する

---

## 操作方法

| キー | 操作 |
|------|------|
| A | 左に移動 |
| S | 右に移動 |
| スペース | ジャンプ |
| Z | 射撃 |
| R | リトライ |

---

## 機能

- キーボードによるキャラクターの移動・ジャンプ・射撃
- 敵キャラクターとの当たり判定
- ゲームオーバー・クリア判定
- BGM・効果音の再生（射撃・ジャンプ・ゲームオーバー・クリア）

> **備考：** BGM フォルダの音声ファイルは著作権上の理由から削除しています。

---

## 使用技術

- HTML5 Canvas
- JavaScript (Vanilla)

---

## 工夫した点

- 外部ライブラリを一切使用せず、Canvas API のみで描画・当たり判定・アニメーションループをすべて自前で実装した
- 射撃・ジャンプ・被弾・クリアなど、場面ごとに効果音を使い分けてゲームの手触りを向上させた
